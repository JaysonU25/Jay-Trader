# Jay Trader Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the React SPA that reads the Jay Trader API and renders seven views, deployable as static assets to Cloudflare Pages.

**Architecture:** Vite builds a static bundle with no SSR. React Router owns navigation, TanStack Query owns fetching and caching, and a thin typed client wraps `fetch` against `VITE_API_BASE`. Charts go through one ECharts wrapper that reads theme tokens from CSS custom properties, so light and dark are two validated palettes rather than an automatic inversion.

**Tech Stack:** React 19, TypeScript 5, Vite 6, React Router 7, TanStack Query 5, ECharts 5, Vitest, Testing Library, MSW 2.

## Global Constraints

- Node 24. Package manager is `npm`. All commands run from `apps/web`.
- Every API response type must match `apps/api/src/marketpulse/api/schemas.py` field-for-field. Field names are snake_case on the wire and stay snake_case in TypeScript — no renaming layer.
- API base URL comes from `import.meta.env.VITE_API_BASE`. Never hardcode a host.
- No test may hit the network. MSW intercepts every request.
- **Charts — non-negotiable, from the dataviz skill:**
  - Never a dual-axis chart. Two measures of different scale get indexed to a common base or split into separate charts.
  - Categorical hues are assigned in fixed slot order and **follow the entity, not its rank**. Removing a series never repaints the survivors.
  - Sequential encoding (magnitude) uses the single blue ramp, light to dark. Never a rainbow.
  - Lines are 2px. Markers are ≥8px. Grid and axes are recessive.
  - Two or more series always carry a legend; four or fewer are also direct-labeled. One series carries no legend — the title names it.
  - Every chart view has a table toggle rendering the same data. This is also the required relief for the three light-mode palette slots that fall below 3:1 contrast (aqua, yellow, magenta).
  - Line charts carry a crosshair and tooltip. Bar charts carry a per-mark hover tooltip.
  - Text uses ink tokens, never a series color.
  - Status colors (`good`/`warning`/`serious`/`critical`) are reserved for pipeline state and always ship with a label, never color alone.
- **Validated palette** (from `dataviz/references/palette.md`, re-validated 2026-09-09 — both modes report ALL CHECKS PASS):

## Data reality as of 2026-09-09

The API is live but three sources are broken or degraded. The frontend must render correctly against what actually exists, and empty states are a shipping requirement, not a placeholder.

| Endpoint | Rows today | View impact |
|---|---|---|
| `/v1/series?category=fx` | 46 series, ~265k observations | FX view fully populated |
| `/v1/series?category=rates\|inflation\|labor\|growth` | 15 series, ~90k observations | Macro view fully populated |
| `/v1/news` | 2,666 | News view populated |
| `/v1/ratings/{symbol}` | 43 | Ratings populated |
| `/v1/earnings/upcoming` | 2 | Sparse but non-empty |
| `/v1/assets`, `/v1/prices/{symbol}` | 0 | **Markets view renders empty state** |
| `/v1/crypto/top` | 0 | **Crypto view renders empty state** |

Markets and Crypto are built in full and simply have nothing to draw yet. Their empty states are exercised by tests; their populated states are exercised by MSW fixtures.

**Deliberate deviation from the spec.** Spec §9 calls for a crypto treemap. This plan ships a ranked horizontal bar chart plus a dominance stat tile instead. Reason: the job of the data is magnitude comparison across 20 items, and a 20-cell treemap's tail is unlabelable — the dataviz form heuristic puts magnitude comparison on a bar. Part-to-whole is preserved by the dominance tile.

- [ ] **Step 8: Implement the theme module**

`apps/web/src/lib/theme.ts`:

```tsx
import { useCallback, useEffect, useState } from "react";

export type Theme = "light" | "dark";
export type ThemeChoice = Theme | "system";

const KEY = "market-pulse-theme";

function readChoice(): ThemeChoice {
  const stored = localStorage.getItem(KEY);
  return stored === "light" || stored === "dark" ? stored : "system";
}

function resolve(choice: ThemeChoice): Theme {
  if (choice !== "system") return choice;
  return matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
}

function stamp(choice: ThemeChoice): void {
  const root = document.documentElement;
  if (choice === "system") root.removeAttribute("data-theme");
  else root.setAttribute("data-theme", choice);
}

export function useTheme() {
  const [choice, setChoice] = useState<ThemeChoice>(readChoice);

  useEffect(() => {
    stamp(choice);
  }, [choice]);

  const setTheme = useCallback((next: ThemeChoice) => {
    if (next === "system") localStorage.removeItem(KEY);
    else localStorage.setItem(KEY, next);
    setChoice(next);
  }, []);

  return { theme: resolve(choice), choice, setTheme };
}

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();
  const next: Theme = theme === "dark" ? "light" : "dark";
  return (
    <button type="button" onClick={() => setTheme(next)}>
      Switch to {next}
    </button>
  );
}
```

```ts
export class ApiError extends Error {
  readonly status: number;
  readonly detail: string;

  constructor(status: number, detail: string) {
    super(`${status}: ${detail}`);
    this.name = "ApiError";
    this.status = status;
    this.detail = detail;
  }
}

export type QueryParams = Record<string, string | number | undefined | null>;

const BASE = import.meta.env.VITE_API_BASE ?? "";

function buildUrl(path: string, params?: QueryParams): string {
  const url = new URL(path, BASE || window.location.origin);
  for (const [key, value] of Object.entries(params ?? {})) {
    if (value !== undefined && value !== null) url.searchParams.set(key, String(value));
  }
  return url.toString();
}

export async function apiGet<T>(path: string, params?: QueryParams): Promise<T> {
  const response = await fetch(buildUrl(path, params), {
    headers: { Accept: "application/json" },
  });

  if (!response.ok) {
    // The API's error body is {"detail": "..."} but a proxy or gateway can
    // answer with HTML or plain text; never let the parse failure mask the status.
    let detail = response.statusText || `HTTP ${response.status}`;
    try {
      const body = (await response.json()) as { detail?: unknown };
      if (typeof body.detail === "string") detail = body.detail;
    } catch {
      /* keep the status-text fallback */
    }
    throw new ApiError(response.status, detail);
  }

  return (await response.json()) as T;
}
```

`apps/web/src/lib/colors.ts`. The stable-slot behavior is the dataviz non-negotiable "color follows the entity, never its rank" — a filter that drops a series must not repaint the survivors.

```ts
import { useRef } from "react";

export const SERIES_SLOTS = [
  "var(--series-1)", "var(--series-2)", "var(--series-3)", "var(--series-4)",
  "var(--series-5)", "var(--series-6)", "var(--series-7)", "var(--series-8)",
] as const;

export function seriesVar(slot: number): string {
  return SERIES_SLOTS[slot % SERIES_SLOTS.length];
}

/** Sequential blue ramp, light to dark. For magnitude, never identity. */
export const SEQUENTIAL = ["var(--seq-200)", "var(--seq-350)", "var(--seq-450)", "var(--seq-600)"] as const;

export function sequentialVar(fraction: number): string {
  const clamped = Math.min(Math.max(fraction, 0), 1);
  const index = Math.round(clamped * (SEQUENTIAL.length - 1));
  return SEQUENTIAL[index];
}

/**
 * Assign a palette slot per id and never reassign it while the hook is mounted.
 * Removing an id frees nothing: survivors keep their color, which is the point.
 */
export function useStableColors(ids: string[]): Map<string, string> {
  const assigned = useRef(new Map<string, string>());
  const nextSlot = useRef(0);

  for (const id of ids) {
    if (!assigned.current.has(id)) {
      assigned.current.set(id, seriesVar(nextSlot.current));
      nextSlot.current += 1;
    }
  }

  return assigned.current;
}
```

```ts
const DIRECT_LABEL_MAX = 4;

function rebase(points: Array<[string, number | null]>): Array<[string, number | null]> {
  const first = points.find(([, v]) => v !== null && v !== 0)?.[1];
  if (first === undefined || first === null) return points;
  return points.map(([d, v]) => [d, v === null ? null : (v / first) * 100]);
}
```

```ts
import { sequentialVar } from "@/lib/colors";

export interface BarInput {
  items: Array<{ label: string; value: number }>;
  valueName: string;
}

export function buildBarOption({ items, valueName }: BarInput): EChartsOption {
  // Ascending, because ECharts draws a horizontal category axis bottom-up:
  // the largest value ends up at the top of the chart where the eye starts.
  const sorted = [...items].sort((a, b) => a.value - b.value);
  const max = Math.max(...sorted.map((i) => i.value), 1);

  return {
    ...baseOption(),
    grid: { left: 8, right: 48, top: 16, bottom: 8, containLabel: true },
    tooltip: { ...baseOption().tooltip, trigger: "item" },
    xAxis: valueAxis(valueName),
    yAxis: {
      type: "category",
      data: sorted.map((i) => i.label),
      axisLine: { show: false },
      axisTick: { show: false },
      axisLabel: { color: INK.secondary, fontSize: 12 },
    },
    series: [
      {
        type: "bar",
        name: valueName,
        data: sorted.map((i) => ({
          value: i.value,
          // Sequential shading: magnitude, not identity.
          itemStyle: { color: sequentialVar(i.value / max) },
        })),
        barMaxWidth: 18,
        itemStyle: { borderRadius: [0, 4, 4, 0] },
      },
    ],
  };
```

```tsx
import { BarChart, LineChart } from "echarts/charts";
import {
  GridComponent, LegendComponent, TooltipComponent,
} from "echarts/components";
import * as echarts from "echarts/core";
import { CanvasRenderer } from "echarts/renderers";
import type { EChartsOption } from "echarts";
import { useEffect, useRef } from "react";

import { useTheme } from "@/lib/theme";

echarts.use([
  LineChart, BarChart, GridComponent, TooltipComponent, LegendComponent, CanvasRenderer,
]);

export function Chart({
  option,
  height = 320,
  ariaLabel,
}: {
  option: EChartsOption;
  height?: number;
  ariaLabel: string;
}) {
  const host = useRef<HTMLDivElement>(null);
  const instance = useRef<echarts.ECharts | null>(null);
  const { theme } = useTheme();

  useEffect(() => {
    if (!host.current) return;
    instance.current = echarts.init(host.current, undefined, { renderer: "canvas" });
    const observer = new ResizeObserver(() => instance.current?.resize());
    observer.observe(host.current);
    return () => {
      observer.disconnect();
      instance.current?.dispose();
      instance.current = null;
    };
  }, []);

  useEffect(() => {
    // `theme` is a dependency because ECharts resolves CSS custom properties at
    // draw time — a theme switch needs a redraw to pick up the new values.
    instance.current?.setOption(option, { notMerge: true });
  }, [option, theme]);

  return <div ref={host} role="img" aria-label={ariaLabel} style={{ height, width: "100%" }} />;
}
```

```tsx
import type { ObservationOut, SeriesOut } from "@/lib/types";

const MACRO_CATEGORIES = ["rates", "inflation", "labor", "growth"];

function SeriesPanel({
  series,
  selected,
  onToggle,
}: {
  series: SeriesOut[];
  selected: string[];
  onToggle: (id: string) => void;
}) {
  return (
    <fieldset className="card" style={{ marginBottom: 16, border: "1px solid var(--border)" }}>
      <legend style={{ color: "var(--text-secondary)", fontSize: 12 }}>Series</legend>
      <div style={{ display: "flex", flexWrap: "wrap", gap: 12 }}>
        {series.map((s) => (
          <label key={s.external_id} style={{ display: "flex", gap: 6, alignItems: "center" }}>
            <input
              type="checkbox"
              checked={selected.includes(s.external_id)}
              onChange={() => onToggle(s.external_id)}
            />
            {s.name}
          </label>
        ))}
      </div>
    </fieldset>
  );
}

/** One hook call per selected series; the count is bounded by the fixed universe. */
function useSelectedObservations(selected: string[]): Record<string, ObservationOut[]> {
  const a = useObservations("fred", selected[0]);
  const b = useObservations("fred", selected[1]);
  const c = useObservations("fred", selected[2]);
  const d = useObservations("fred", selected[3]);

  return useMemo(() => {
    const out: Record<string, ObservationOut[]> = {};
    [a, b, c, d].forEach((query, i) => {
      const id = selected[i];
      if (id && query.data) out[id] = query.data;
    });
    return out;
  }, [a.data, b.data, c.data, d.data, selected]);
}

export function Macro() {
  const catalogue = useSeries();
  const [selected, setSelected] = useState<string[] | null>(null);

  const macroSeries = useMemo(
    () => (catalogue.data ?? []).filter((s) => MACRO_CATEGORIES.includes(s.category)),
    [catalogue.data],
  );

  // Default to the first series so the view is never blank on arrival.
  const active = selected ?? (macroSeries.length > 0 ? [macroSeries[0].external_id] : []);
  const capped = active.slice(0, 4);
  const colors = useStableColors(capped);
  const observations = useSelectedObservations(capped);

  const toggle = (id: string) =>
    setSelected((current) => {
      const base = current ?? active;
      return base.includes(id) ? base.filter((x) => x !== id) : [...base, id];
    });

  const lineSeries: LineSeries[] = capped.map((id) => ({
    id,
    name: macroSeries.find((s) => s.external_id === id)?.name ?? id,
    color: colors.get(id) ?? "var(--series-1)",
    points: (observations[id] ?? []).map((o) => [o.obs_date, o.value] as [string, number | null]),
  }));

  // Units differ across FRED series (Percent, Index, Thousands of Persons), so
  // an overlay of more than one must be indexed — a second y-axis is never an option.
  const indexed = lineSeries.length > 1;

  if (catalogue.isLoading) return <Loading label="Loading series catalogue" />;
  if (catalogue.isError) return <ErrorState error={catalogue.error} onRetry={() => catalogue.refetch()} />;

  return (
    <>
      <h1>Macro</h1>
      <SeriesPanel series={macroSeries} selected={capped} onToggle={toggle} />
      {capped.length === 0 ? (
        <EmptyState title="Select at least one series" hint="Pick up to four to overlay." />
      ) : (
        <ChartFrame
          title={indexed ? "Indexed comparison" : lineSeries[0].name}
          chart={
            <Chart
              option={buildLineOption({
                series: lineSeries,
                indexed,
                yName: indexed ? undefined : (macroSeries.find((s) => s.external_id === capped[0])?.unit ?? undefined),
              })}
              ariaLabel={indexed ? "Indexed macro comparison" : lineSeries[0].name}
            />
          }
          table={
            <DataTable
              caption={indexed ? "Indexed comparison" : lineSeries[0].name}
              columns={[
                { key: "date", header: "Date" },
                ...capped.map((id) => ({
                  key: id,
                  header: macroSeries.find((s) => s.external_id === id)?.name ?? id,
                  align: "right" as const,
                })),
              ]}
              rows={Array.from(
                new Set(capped.flatMap((id) => (observations[id] ?? []).map((o) => o.obs_date))),
              )
                .sort()
                .reverse()
                .slice(0, 100)
                .map((date) => {
                  const row: Record<string, string | number | null> = { date: formatDate(date) };
                  for (const id of capped) {
                    const hit = (observations[id] ?? []).find((o) => o.obs_date === date);
                    row[id] = hit && hit.value !== null ? formatNumber(hit.value) : null;
                  }
                  return row;
                })}
            />
          }
        />
      )}
    </>
  );
}
```
